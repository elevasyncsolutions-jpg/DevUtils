# DevUtils — Developer Toolbox

A single HTML page with **10 client-side developer tools**:

- JSON Formatter & Validator
- CSV ⇄ JSON Converter
- Hash Generator (MD5, SHA1, SHA256, SHA512, SHA3)
- JWT Debugger
- Base64 Encode / Decode
- UUID Generator (v4, v7)
- Case Converter (camelCase, PascalCase, snake_case, kebab-case, UPPER_CASE, lowercase)
- Timestamp Converter (Unix ↔ Date)
- Color Converter (HEX, RGB, HSL)
- Regex Tester

100% client-side — no data leaves your browser. Built with vanilla JS and Tailwind CSS.
